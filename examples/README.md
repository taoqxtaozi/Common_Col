# Examples

This directory contains example workflows generated and executed under different tree topologies and reference selection modes.

The examples cover different input tree structures and reference settings, including:

- fully resolved binary trees;
- single polytomies;
- rooted trees with the root node as a polytomy;
- rooted trees with the root node as a binary node;
- cases where the reference genome is located at different positions in the tree;
- fixed global reference mode;
- no-fixed-reference mode.

Each example was generated using `make_plan.sh` and executed following the commands provided in the generated `instruction.txt`.

---

## Contents of each example archive

Each compressed example archive contains:

```
example/
├── genome files
├── aln.tre
├── genome.txt
├── instruction.txt
├── finalization.sh
├── intermediate files and final results
├── rerun/
└── README.txt
```

### Input files

- **Genome files**

  Input genome FASTA files used for the alignment workflow.

- **`aln.tre`**

  The rooted input tree used for planning.

- **`genome.txt`**

  The genome path file containing taxon names and corresponding genome FASTA paths.

---

### Generated workflow files

- **`instruction.txt`**

  The workflow commands generated by `make_plan.sh`.

  These commands include:
  
  - Progressive Cactus alignment;
  - HAL-to-MAF conversion;
  - consensus extraction;
  - ancestor inference;
  - higher-level alignment construction.

- **`finalization.sh`**

  The script used to generate the final output alignment files after all commands in `instruction.txt` are completed.

---

### Output files

Each archive also contains the intermediate files and final results generated by running the commands in `instruction.txt`, including:

- intermediate alignment files;
- inferred ancestor genomes;
- consensus alignments;
- final alignment outputs.

---

### Reproduction files

- **`rerun/`**

  Contains files required to reproduce the example workflow.

- **`README.txt`**

  Provides the commands required to rerun the example and reproduce the results.

---

## Reproducing an example

To reproduce an example workflow:

1. Download and extract the corresponding archive.

2. Enter the example directory:

```bash
cd example_directory
```

3. Follow the commands provided in `README.txt`.
