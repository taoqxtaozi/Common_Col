# Examples

This directory contains several example runs of the pipeline.

Each `try*` directory contains the input files needed to generate an `instruction.txt` file, including:

- `aln.tre`: the input guide tree
- `genome.txt`: the two-column genome path file

Each `try*` directory also contains a `CreateByPipeline/` folder. This folder stores the `instruction.txt` file generated by the planner and the results produced by running the commands listed in that `instruction.txt`. In other words, the contents of `CreateByPipeline/` are precomputed example outputs.

Users can reproduce these examples by entering each `try*` directory, running the planner command below, and then copying and running the commands listed in the generated `instruction.txt`.

## Reproduce try1, try3, try4, and try5

For `try1`, `try3`, `try4`, and `try5`, the reference taxon is `GALGA`.

Enter the corresponding directory:

```bash
cd try1
```

or:

```bash
cd try3
```

or:

```bash
cd try4
```

or:

```bash
cd try5
```

Then run:

```bash
bash ../../make_plan_UseThis.sh \
  --tree-file aln.tre \
  --paths genome.txt \
  --reference GALGA \
  --threads 15 \
  --common_workers 5
```

This command generates an `instruction.txt` file in the working directory. To run the example, copy and execute the commands listed in `instruction.txt`.

## Reproduce try2

The global guide tree file `aln.tre` in `try2` is the same as the one used in `try1`, but the reference taxon is changed from `GALGA` to `TAEGU`.

Enter the `try2` directory:

```bash
cd try2
```

Then run:

```bash
bash ../../make_plan_UseThis.sh \
  --tree-file aln.tre \
  --paths genome.txt \
  --reference TAEGU \
  --threads 15 \
  --common_workers 5
```

This command generates an `instruction.txt` file in the working directory. To run the example, copy and execute the commands listed in `instruction.txt`.
