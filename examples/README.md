# Examples

This directory provides several complete example runs of the Common-col pipeline.

Each example (`try1`, `try2`, `try3`, `try4`) contains both:

- **precomputed results** (already successfully executed)
- **rerun instructions** (to reproduce the results)

---

## Structure of each example

Each `tryX/` directory has the following structure:

```
tryX/
├── aln.txt
├── aln.tre
├── ... (pipeline-generated files and directories)
├── output files (e.g., *.maf, *.fasta, *.hal, ancestor.fa)
└── rerun/
    └── README.md
```

### Components

- `aln.txt`  
  Genome path file used as input.  
  Although `aln.txt` may contain taxa not present in `aln.tre`, the pipeline automatically identifies and uses only the taxa specified in `aln.tre`.

- `aln.tre`  
  Rooted tree used for the run.

- Other files and directories  
  These are **generated by the pipeline**, including:
  - intermediate files
  - working directories
  - final outputs (consensus alignment and inferred ancestor)

- `rerun/`  
  Contains instructions to **reproduce the entire workflow from scratch**.

---

## Reproducing an example

To rerun an example:

```bash
cd try1/rerun
```

Then follow the instructions in:

```bash
README.md
```

Each `rerun/README.md` contains the exact commands needed to reproduce the corresponding example.
